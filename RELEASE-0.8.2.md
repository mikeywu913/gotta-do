# Gotta Do! 0.8.2

## 更新内容

- 随手记自动打开最近编辑的笔记。空库可直接输入，新增 Markdown 格式工具与离线预览。
- 音频快捷键可再次点击关闭。日历、日志、周报、音频和随手记共用一个滑出设置。
- 统一滚动条样式，修复日志双滚动及对话框关闭按钮。
- 优化桌面固定与唤出流程，继续支持 Win+D 后显示。
- 便携包包含 Whisper 中英文离线转写模型。

下载 [Windows Portable ZIP](https://github.com/mikeywu913/gotta-do/releases/download/v0.8.2/Gotta-Do-0.8.2-Windows-Portable.zip)，完整解压后运行 **Gotta Do!.exe**。从托盘退出旧版，再将旧程序旁的整个 `Notes` 文件夹复制到新版旁，包含 `.index.json`。推荐 Windows 11 x64。

## What's new

- Notes open the most recently edited document. Start typing in an empty library, use Markdown formatting tools, and preview offline.
- Click the audio shortcut again to close it. One setting controls sliding windows for Calendar, Log, Weekly Report, Audio, and Notes.
- Consistent scrollbars, a single log scrollbar, and corrected dialog close controls.
- Improved desktop pinning and window activation with continued Win+D support.
- Includes an offline Whisper model for Chinese and English transcription.

Download the [Windows Portable ZIP](https://github.com/mikeywu913/gotta-do/releases/download/v0.8.2/Gotta-Do-0.8.2-Windows-Portable.zip), extract the full archive, and run **Gotta Do!.exe**. When upgrading, quit the old app from the tray and copy the entire `Notes` folder, including `.index.json`, beside the new executable. Windows 11 x64 recommended.
