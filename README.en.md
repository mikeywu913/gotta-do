## Download and run

| System | Download | Version |
| --- | --- | --- |
| Windows 11 x64 recommended | [Portable ZIP](https://github.com/mikeywu913/gotta-do/releases/download/v0.8.2/Gotta-Do-0.8.2-Windows-Portable.zip) | 0.8.2 public preview |

1. Extract the **entire ZIP** into a folder you can write to.
2. Open **Gotta Do!.exe** in the extracted folder. Node.js is unnecessary.
3. Use the named Portable ZIP release asset. GitHub's generated Source code archives are not runnable packages.

The executable is unsigned. The release includes `SHA256SUMS.txt` to verify the download.

## Getting started

| To do this | Open |
| --- | --- |
| Capture a task | Select the yellow **Add task** button. Add tags and a time block to see it on the calendar. |
| Keep tasks on your desktop | Enable **Pin to desktop** in Settings. The window remains visible when you return to the desktop with Win+D. |
| Record and transcribe | Select the microphone, stop recording, then choose **Transcribe** from the recording menu. Built-in offline Whisper needs no API key. |
| Take notes and review your work | Use the Notes, Log, and Weekly Review icons. Notes support Markdown editing and preview. |
| Change language or appearance | Open Settings to switch to English or Chinese and adjust appearance and sliding windows. |

## Upgrading

Quit the old app from the tray and extract the new version into a fresh folder. The app continues to use your local tasks and settings. Copy the entire **Notes** folder beside the old executable to the new folder, including `.index.json`.
