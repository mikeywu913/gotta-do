# Gotta Do!

Windows 桌面任务助手：可缩放磨砂窗口、任务与日历、中英文界面、AI 输入和 Skill 指令模板。

A desktop task companion for Windows with a resizable glass window, calendar, bilingual UI, and configurable AI capture.

**[下载 Windows 测试版 / Download Windows preview](https://github.com/mikeywu913/gotta-do/releases/tag/v0.5.0)** · [测试指南](TESTING.md) · [AI 配置](AI-SETUP.md) · [反馈问题](https://github.com/mikeywu913/gotta-do/issues/new/choose)

当前版本：**0.5.0 开发预览版 / Pre-release**。推荐 Windows 11 x64。无需 Node.js；完整解压 Portable ZIP 后运行 Gotta Do!.exe。不要下载自动生成的 Source code ZIP 来运行软件。

基础任务与本机规则提取无需 AI 账号。云端模型与语音需要使用自己的服务商凭证，费用由相应服务商收取。
